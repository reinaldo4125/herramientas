Código P0141: Circuito del Calentador del Sensor de Oxígeno (Banco 1, Sensor 2)

Resumen en 30 Segundos: Código P0141

El código P0141 indica que el elemento calefactor del sensor de oxígeno trasero (Sensor 2), ubicado después del convertidor catalítico, está defectuoso o no recibe alimentación. Este sensor monitorea la eficiencia del catalizador.

Severidad: Baja-Media
Dificultad: Fácil
Afecta: Monitor de Catalizador

Síntomas del Código P0141

  • Luz Check Engine encendida en el cuadro.
  • Rendimiento del motor casi normal (a diferencia del Sensor 1, el Sensor 2 no ajusta la mezcla primaria).
  • El monitor OBD2 del catalizador permanece en estado "Incompleto / No Ready".
  • Rechazo en la inspección técnica o verificación de gases contaminantes.

Causas Frecuentes

Calefactor Abierto

La resistencia interna del sensor trasero está rota. La solución es sustituir el sensor O2 secundario.

Cable Rozado con el Tubo de Escape

Al estar debajo del chasis, el cable suele engancharse o quemarse contra el escape metálico.
